# ASTRAWELL
Autonomous Astronaut Health Intelligence and Decision Support System

## Current stage
Phase 1 — project structure and data foundation.

This is a software prototype using synthetic demonstration data. It is not a medical device and does not diagnose or prescribe treatment.

## Setup (Windows PowerShell)
```powershell
cd ASTRAWELL
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```
